Portable ANSI C MATLAB File Exporter
Version 2.0

Author: Malcolm McLean

Original source obtained from the MathWorks File Exchange:
https://www.mathworks.com/matlabcentral/fileexchange/26731-portable-matfile-exporter-in-c

This code exports data from C/C++ programs into MATLAB .mat format.
